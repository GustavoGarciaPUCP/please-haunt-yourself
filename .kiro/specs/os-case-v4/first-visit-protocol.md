# First-visit protocol (v4)

A short observation script for one person who has not seen the project and does not program. **Nobody was available during the November 7 Kiro session, so this has not been run.** Automated walkthroughs in `tasks.md` are not a substitute.

## Setup (5 minutes)

1. `npm.cmd run build`, then `npm.cmd run preview -- --port 5174 --strictPort`.
2. Open a **private window** at `http://127.0.0.1:5174/haunt.html` at 1366×768 or larger. A private window gives a fresh desk: the boot line, the callout and an open job. Check that About HAUNT OS says *build v4*.
3. Sound stays off unless the participant turns it on.

## Say only this

"This is a fictional computer. Something on it is unfinished. Do what you think makes sense. Please think aloud. I won't help unless you ask, and you can stop at any time."

## Observe (do not prompt)

Note the time at each moment. Write down the words the person uses.

| Moment | What to note |
| --- | --- |
| First action | Did they find Look inside or type? How long did it take? |
| The bell | Did they try Muffle the bell first? Did they understand why it still came back? |
| The glass | Did they notice the hand at TERMINAL's edge? Did they move the window? |
| ECHO | Did they pick Desktop glass? Did they read the subject chips? Did they understand "Full image kept. This frame becomes the picture."? |
| CANVAS | Did they understand Lift the writing before trying the Mist slider? Did "Not the words." lead them to Undo? |
| POSTMAN | Who did they send it to first, and why? What did they think "That went back to the sender." meant? |
| The end | Did they read "You were the next person"? Did they notice the glass clearing, or only the letter? |
| Help | Which hints did they open, and at which phase? |

## Ask afterwards (3 questions)

1. "What happened, in your own words?"
2. "Who was the letter for?"
3. "Was there a moment you felt stuck or unsure?"

## Record honestly

Record the total time and the time per phase, every place where they got stuck and every help request, plus any wrong recipient and how they recovered. If nobody tests it, say so. Do not report agent walkthroughs as people.
